Stop re-testing the same losing idea in a new market.

Learnings from CRM, Incentives and Rewards tests currently live across dashboards, Slack threads, readout docs and personal memory. When someone leaves or moves teams, that memory is gone. This is the first version of Layer E: a searchable, tagged store of what has already been tested and decided.
